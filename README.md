# 🤖 AI News Monitoring & Daily Digest System

সম্পূর্ণ **ফ্রি (100% FREE)** এবং লোকাল পিসিতে চালিত একটি শক্তিশালী এআই নিউজ মনিটরিং ও ডেইলি ডাইজেস্ট সিস্টেম। এটি বিভিন্ন শীর্ষস্থানীয় ও নির্ভরযোগ্য উৎস (OpenAI, DeepMind, TechCrunch, ArXiv, Hacker News ইত্যাদি) থেকে সর্বশেষ এআই খবর সংগ্রহ করে, একই ঘটনার একাধিক রিপোর্ট কঠোরভাবে ডিডুপ্লিকেট করে, গুগল জেমিনাই এআই (Gemini Free API) দিয়ে বিশ্লেষণ ও ইমপ্যাক্ট স্কোরিং (১-১০) করে এবং প্রতিদিন ৩ বার নির্দিষ্ট সময়ে টেলিগ্রামে ডাইজেস্ট মেসেজ পাঠিয়ে দেয়। একইসাথে লোকালহোস্টে একটি মিনিমালিস্ট লাইভ ড্যাশবোর্ড সরবরাহ করে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

- **সম্পূর্ণ ফ্রি (100% Free)**: লোকাল পিসিতে চলাকালীন কোনো পেইড সাবস্ক্রিপশন বা ক্লাউড সার্ভার খরচ নেই।
- **কিউরেটেড এআই সোর্স (Curated Sources)**: OpenAI News, Google DeepMind, Hugging Face, TechCrunch AI, VentureBeat, ArXiv Research Papers এবং Hacker News AI।
- **কঠোর ডুপ্লিকেট বাদ দেওয়া (Strict Deduplication)**: বিভিন্ন মিডিয়ায় একই খবরের পুনরাবৃত্তি শনাক্ত করে কেবল প্রথম/সেরা সোর্সটি রেখে বাকি সব ডুপ্লিকেট বাদ দেওয়া হয়।
- **বাইলিঙ্গুয়াল এআই সামারি ও র‍্যাঙ্কিং**: গুগল জেমিনাই (Gemini Free Tier) দিয়ে ইংরেজি মূল শিরোনামের সাথে বাংলা ভাষায় ৩-লাইনের সুস্পষ্ট সারসংক্ষেপ (কী ঘটেছে, কেন গুরুত্বপূর্ণ, ফলাফল) এবং ১-১০ স্কেলে ট্রেন্ডিং স্কোর।
- **নির্দিষ্ট শিডিউলে টেলিগ্রাম ডাইজেস্ট (Telegram Bot)**:
  - 🌅 **সকাল ১০:০০ টা (10:00 AM)** - মর্নিং ডাইজেস্ট
  - ☀️ **দুপুর ০২:০০ টা (02:00 PM)** - আফটারনুন ডাইজেস্ট
  - 🌙 **রাত ০৯:০০ টা (09:00 PM)** - নাইট ডাইজেস্ট
- **লোকাল লাইভ ড্যাশবোর্ড (Live Dashboard)**: `http://localhost:8000` এ তাৎক্ষণিক সার্চ, ট্রেন্ডিং বনাম লেটেস্ট ভিউ, ক্যাটাগরি ফিল্টার এবং ম্যানুয়াল "Fetch Now" বাটন।
- **উইন্ডোজ ব্যাকগ্রাউন্ড সার্ভিস (Windows Autostart)**: পিসি চালু করলেই কোনো উইন্ডো ছাড়া স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে চালু রাখার সুবিধা।

## ⚙️ কনফিগারেশন সেটআপ (.env Setup)

প্রজেক্টের রুট ফোল্ডারে একটি `.env` ফাইল রয়েছে। ফাইলটি যেকোনো টেক্সট এডিটরে ওপেন করে আপনার তথ্য বসান:

```env
# ১. গুগল জেমিনাই ফ্রি এপিআই কি
# সংগ্রহ করুন: https://aistudio.google.com/
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash

# ২. টেলিগ্রাম বট কনফিগারেশন
# বট তৈরি করুন: https://t.me/BotFather (@BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token_here

# আপনার টেলিগ্রাম চ্যাট আইডি (টেলিগ্রামে @userinfobot এ হাই পাঠিয়ে চ্যাট আইডি পান)
TELEGRAM_CHAT_ID=your_telegram_chat_id_here

# ৩. ক্রলার ইন্টারভাল ও টাইমজোন
FETCH_INTERVAL_MINUTES=30
TIMEZONE=Asia/Dhaka
```

> **নোট**: API Key বা Telegram Token না বসালেও সিস্টেমটি ক্রাশ করবে না; এটি হিউরিস্টিক মোডে লোকাল ড্যাশবোর্ডে নিউজ প্রদর্শন করতে থাকবে। কী যুক্ত করলে সাথে সাথে AI এনালাইসিস এবং টেলিগ্রাম পুশ চালু হবে।

## 🚀 যেভাবে চালাবেন (How to Run)

### পদ্ধতি ১: সাধারণ রান (Manual Run)
প্রজেক্ট ফোল্ডারে থাকা **`run.bat`** ফাইলে ডাবল-ক্লিক করুন।
- এটি ব্যাকএন্ড ও শিডিউলার চালু করবে।
- স্বয়ংক্রিয়ভাবে আপনার ব্রাউজারে `http://localhost:8000` ওপেন করবে।

### পদ্ধতি ২: উইন্ডোজ ব্যাকগ্রাউন্ড অটোস্টার্ট (Windows Autostart)
আপনি যদি চান পিসি অন হওয়ার সাথে সাথে কোনো উইন্ডো ছাড়াই ব্যাকগ্রাউন্ডে সিস্টেমটি কাজ করুক এবং সময়ে সময়ে টেলিগ্রামে মেসেজ পাঠাক:
1. **`setup_autostart.bat`** ফাইলে ডাবল ক্লিক করুন। (এটি স্টার্টআপে রেজিস্টার করবে)
2. তাৎক্ষণিক ব্যাকগ্রাউন্ডে চালু করতে **`start_background.vbs`** ফাইলে ডাবল ক্লিক করুন।
3. কখনো বন্ধ করতে চাইলে **`stop_background.bat`** চালান।
4. অটোস্টার্ট ডিলিট করতে চাইলে **`uninstall_autostart.bat`** চালান।

## 🖥️ ড্যাশবোর্ড ইন্টারফেস (Dashboard)

ব্রাউজারে যান: **`http://localhost:8000`**
- **🔥 Trending Stories**: শীর্ষ ইমপ্যাক্ট স্কোর (৭.৫+) পাওয়া খবরের তালিকা।
- **⚡ Latest Stream**: সময়ানুসারে সব খবরের লাইভ ফিড।
- **🔍 Search**: নির্দিষ্ট কোম্পানি বা টপিক (যেমন: Claude, Gemini, DeepSeek) লিখে ফিল্টার।
- **🚀 Fetch Now**: নতুন কোনো খবর এসেছে কিনা তা সাথে সাথে ক্রল করার বাটন।
- **✈️ Send Digest**: টেলিগ্রাম বট কানেকশন ঠিক আছে কিনা তা এখনই টেস্ট করার জন্য একটি ডাইজেস্ট পাঠানোর বাটন।
